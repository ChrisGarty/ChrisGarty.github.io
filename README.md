# Chris Garty — Youth Soccer Coaching

Personal youth-soccer coaching blog published with GitHub Pages and Jekyll.

## Draft workflow

Drafts live in `_drafts`. To publish one, move it to `_posts` and name it `YYYY-MM-DD-short-title.md`. Update the date in its front matter to match.

Create future articles by copying `_drafts/weekly-post-template.md`.

This is an independent personal site and is not an official Tri City United publication.
